 Portafolio Personal - ICINF1107

Descripción:
Este repositorio contiene mi portafolio web personal desarrollado como proyecto para la asignatura de Desarrollo de Frontend. El objetivo principal es mostrar mis proyectos universitarios y habilidades a posibles reclutadores o clientes.

Lenguajes Utilizados:
- HTML5 Semántico
- CSS3 (Diseño Responsivo con 3 breakpoints)

Diseño:
- Audiencia: El portafolio está diseñado para reclutadores técnicos y docentes académicos. Su necesidad principal es evaluar mis competencias prácticas en pocos segundos. Por ello, la navegación va directo al grano, evitando animaciones excesivas que retrasen la lectura. 
- Estructura y Jerarquía:Ubiqué la sección de "Proyectos" inmediatamente después de mi presentación breve. Destaqué en primer lugar la web de perros Dachshund y el calendario organizador porque demuestran mi versatilidad para crear tanto sitios informativos como herramientas funcionales de gestión de tiempo.
- Estética y Colores: Diseño minimalista. Azul oscuro en header/footer para un tono tecnológico y profesional, fondo gris claro para resaltar el contenido, y azul vibrante en el botón de envío[span_4](start_span)[span_4](end_span)[span_5](start_span)[span_5](end_span).
- Accesibilidad: Alto contraste de lectura[span_6](start_span)[span_6](end_span)[span_7](start_span)[span_7](end_span), etiquetas (`<label>`) explícitas en el formulario para lectores de pantalla[span_8](start_span)[span_8](end_span), y jerarquía visual clara mediante tipografías[span_9](start_span)[span_9](end_span).
