​Declaración de Uso de Inteligencia Artificial (IA)


​Durante el desarrollo de este proyecto, utilicé asistencia de Inteligencia Artificial (Gemini) como herramienta de apoyo al aprendizaje y consulta técnica. Los usos principales fueron:
​
1. Consulta de buenas prácticas y estándares:
Se utilizó la IA para consultar la forma más óptima de estructurar el árbol de carpetas de un proyecto web y repasar el uso correcto de las etiquetas de HTML5 semántico (<header>, <main>, <article>).
​
2. Revisión de accesibilidad y CSS:
Consulté la teoría y sintaxis de los breakpoints (Media Queries) para asegurar el correcto funcionamiento del diseño responsivo, y revisé los estándares WCAG aplicables a formularios (uso de <label>) para garantizar que la interfaz fuera accesible.
​
3. Apoyo en la configuración de GitHub:
Se utilizó para aclarar dudas sobre cómo arreglar las rutas relativas de los archivos tras subir el proyecto al repositorio y confirmar los pasos para el despliegue en GitHub Pages.
​
4. Preparación y simulacro de presentación:
Utilicé la IA como apoyo para estructurar el formato de mi archivo README.md y le pedí que me generara un pequeño cuestionario técnico sobre mi propio código para repasar los conceptos antes de la presentación oral.
